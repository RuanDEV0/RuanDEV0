## Projetos que valem uma olhada

### 🌱 EcoWeb

Uma ideia que virou três aplicações.

O EcoWeb conecta empresas que geram resíduos recicláveis a pessoas interessadas em dar uma nova utilidade a esses materiais.

O projeto foi dividido em:

- [Mobile](https://github.com/Project-EcoWeb/mobile) — React Native
- [API](https://github.com/Project-EcoWeb/api) — Node.js + MongoDB
- [Website](https://github.com/Project-EcoWeb/web) — React + Next.js

🔗 [Acessar o EcoWeb](https://ecoweb-cop30.vercel.app/)

### 🏛️ InspectGovBr

**Python • Django • PostgreSQL**

Uma aplicação web voltada à auditoria de repasses de recursos públicos.

A proposta é utilizar tecnologia para ajudar na análise e organização de informações sobre recursos públicos.

🔗 [Repositório](https://github.com/RuanDEV0/InspectGovRR)

### 💰 Cofrinho

**Node.js • PostgreSQL • Open Finance**

Projeto final do meu estágio na Compass UOL.

Uma API RESTful para gerenciar despesas compartilhadas, com integração bancária via Open Finance.

🔗 [Repositório](https://github.com/Cofrinho/backend)
